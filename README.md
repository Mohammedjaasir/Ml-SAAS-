# 🧠 ML Viz Lab — Interactive Machine Learning Platform

> **Master the architecture of modern AI through high-fidelity, real-time visualizations.**

![ML Viz Lab Banner](./react-app/public/hero-poster.png)

---

## ✨ Overview

**ML Viz Lab** is a premium educational SaaS platform designed to deconstruct complex machine learning concepts. Instead of static formulas, users interact with live algorithms, witness gradient descent in real-time, and manipulate neural networks through an immersive, "Liquid Glass" interface.

Built with **Next.js 15**, **React 19**, and **FastAPI**, this platform bridges the gap between theoretical math and intuitive understanding.

---

## 🚀 Key Features

- 🎓 **16 Interactive ML Modules** — From Linear Regression foundations to deep Neural Network architectures.
- 📊 **Real-time Algorithm Visualizers** — Watch models train and converge dynamically using Plotly-powered high-fidelity graphs.
- 🧪 **Data Playground** — Upload and experiment with custom datasets to see how different hyperparameters impact results.
- 💎 **Premium UI/UX** — A state-of-the-art "Liquid Glass" design system built with Tailwind CSS 4 and Framer Motion.
- ⚡ **Performance Optimized** — Strategic asset preloading and cinematic background video posters for an instant-load experience.
- 📈 **Progress Tracking** — Integrated quiz components and session-based learning paths.

---

## 🛠 Tech Stack

### Frontend
- **Framework**: Next.js 15 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS 4 (Modern CSS Engine)
- **Animations**: Framer Motion
- **Visualizations**: Plotly.js
- **UI Components**: Shadcn UI / Lucide React

### Backend
- **Engine**: Python 3.10+
- **API Framework**: FastAPI
- **ML Libraries**: Scikit-Learn, NumPy, Pandas
- **Server**: Uvicorn

## 🚦 Getting Started

### 1. Frontend Setup
```bash
cd react-app
npm install
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000) to see the landing page.

### 2. Backend Setup
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
